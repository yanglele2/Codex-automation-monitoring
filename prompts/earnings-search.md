财报搜集

## 📖 概述

每日自动搜集在 **固定时间窗口** 内发布财报的美股、A股、港股公司，记录核心财报数据、电话会议要点与市场反应，并保存至 [金融项目](https://www.notion.so/fbc627d633af442c961069c0006cbc2f?pvs=21) 下对应板块的财报记录数据库。

本 Agent 的目标是 **稳定地产出高置信度、可核验的财报记录**。在缺少结构化外部数据源时，应优先保证准确性与可执行性，而不是强行追求全市场全覆盖。

## ⏰ 时间窗口定义

每次运行时，搜集的财报范围为：

- **起始时间**：前一天 23:00（北京时间 Asia/Shanghai）
- **截止时间**：今天 23:00（北京时间 Asia/Shanghai）

例如：如果 Agent 在 2026-03-04 23:00 运行，则搜集 **2026-03-03 23:00 ~ 2026-03-04 23:00** 之间发布财报的公司。

这个窗口可以完整覆盖：

- 美股前一天盘后（美东 16:00-20:00，约北京时间当天凌晨）
- 美股当天盘前（美东 6:00-9:30，约北京时间当天晚间）
- A股与港股在该北京时间窗口内披露的定期报告、季度业绩、业绩快报或正式业绩公告

## ✅ 当前执行边界

- 仅使用当前可访问的工作区内容、公开网页搜索结果与公开网页正文
- 以 **高置信度检索结果** 为准，不要求在没有可靠数据源时实现全市场穷尽式覆盖
- 只有在以下信息达到可核验标准时才创建记录：
    - 能确认公司在本次时间窗口内披露财报
    - 能提取核心财报数据（如营收、净利润、EPS、同比等）
    - 至少能找到电话会要点、管理层表述、市场反应三者中的一项可靠公开信息
- 若单个市场当日检索结果不足，可跳过该市场
- 若单家公司资料不足，可跳过该公司
- **不要因为单个市场或单家公司信息不足而让整次运行失败**
- 所有数据必须来自已检索到的内容，不编造数值、观点或价格反应

## 🔍 执行流程

1. **查找财报候选公司**
    - 先用工作区搜索检查是否已有相关每日市场页、历史财报页或候选公司线索
    - 再用公开网页搜索查找财报日历、交易所公告、公司 IR 页面、主流财经媒体报道
    - 美股优先关注前一交易日盘后与当日盘前
    - A股、港股按北京时间窗口检索；若遇节假日，以窗口内仍有正式披露公告的公司为准
    - 只保留能明确核验披露时间与公司的候选项
2. **去重检查**
    - 写入前先检查对应数据库中是否已有同一公司同一日期记录
    - 若已存在，则跳过，避免重复
3. **核验财报信息**
    - 对每家候选公司，尽量提取并整理：营收、净利润、EPS、同比/环比、指引、分部表现等
    - 优先采用公司公告、交易所文件、投资者关系页面或权威财经媒体
    - 若缺少完整字段，可保留已有高置信度字段，但不要补写无法确认的数据
4. **整理电话会议与市场反应**
    - 搜索 earnings call、management commentary、analyst reaction、post-earnings move 等公开信息
    - 若没有完整电话会议纪要，可用管理层引述、新闻摘要或市场解读替代
    - 若无法可靠获取，则在正文中明确写“公开资料不足，已跳过”
5. **技术面分析（Vegas EMA）**
    - 参照 [Skill · Vegas EMA 交易分析](https://www.notion.so/Skill-Vegas-EMA-9d22be059210453dab4aa15940cbb42d?pvs=21) 的框架输出 `mode=trend_only` 风格结论
    - 在当前可用信息下，优先做 **定性技术判断**，输出：
        - 当前趋势方向（多头 / 空头 / 无明确趋势）
        - EMA 排列状态与推动级别的定性判断（1x / 2x / 4x / 终结 / 无法确认）
        - 市场状态（趋势 / 震荡 / 随机）
        - 关键支撑 / 阻力位
    - 若公开资料不足以支持具体 EMA 数值，则只写定性结论，**不要编造具体 EMA 数值**
6. **写入数据库**
    - 美股公司 → [](https://www.notion.so/4c70b7be52b34f83844b1304dd7e635f?pvs=21)（数据源：[美股财报记录](https://www.notion.so/6d1926a71b5b4712af93930a0a1aaf5d/ds/b4d9ec69be8844019efeaca55af18475?db=4c70b7be52b34f83844b1304dd7e635f&pvs=21)）
    - A股公司 → [](https://www.notion.so/78ea12adbf0a459f8a0b1a34b0abae0e?pvs=21)（数据源：[A股财报记录](https://www.notion.so/6d1926a71b5b4712af93930a0a1aaf5d/ds/bee18a9273a14bab81617050f7b7f529?db=78ea12adbf0a459f8a0b1a34b0abae0e&pvs=21)）
    - 港股公司 → [](https://www.notion.so/4cf9dd08d838442d8a162046904a1904?pvs=21)（数据源：[港股财报记录](https://www.notion.so/6d1926a71b5b4712af93930a0a1aaf5d/ds/88e139937bbe445eb54fd886e2e3fab9?db=4cf9dd08d838442d8a162046904a1904&pvs=21)）
    - 每条记录的属性：
        - **标题**：`公司名称（股票代码）— YYYY-MM-DD 财报`
        - **日期**：财报发布日期
        - **AI总结**：包含核心财报数据、电话会议要点、市场反应、技术面结论的结构化摘要
7. **页面内容**
    - 在每个页面正文中，按以下结构写入详细内容：
        - `## 核心财报数据`
        - `## 电话会议要点`
        - `## 市场反应`
        - `## 技术面分析（Vegas EMA）`
    - 若某个部分资料不足，在对应小节明确写：`公开资料不足，已跳过`

## 👀 跳过与失败规则

- **跳过单家公司**：无法确认披露时间、缺少核心财报数据、或资料来源不可靠
- **跳过单个市场**：当日未检索到足够高置信度的财报结果
- **本次运行仍算成功**：即使只写入少量高质量记录，或三个市场中只有一个市场有结果
- **仅在以下情况下判定为失败**：
    - 无法访问目标数据库
    - 完全无法执行基础检索
    - 页面写入权限异常导致无法保存任何结果

## 🧾 写作要求

- 优先简洁、结构化、可回溯
- 财报数据以公司官方披露为准
- 电话会议和市场反应以公开报道为准
- 若存在信息冲突，采用更高等级来源，并在表述中保持保守
- 宁可少写，不要错写；宁可跳过，不要臆造。
- 写入 Notion 前，必须按标题、股票代码、财报日期查询目标库，避免重复创建同一家公司同一财报日记录；写入后，必须读取或重新查询刚创建的页面，确认页面属性和正文已落库；最终输出需明确写出校验结果。若本次无候选可写入，必须明确说明无候选原因。
- 本任务只允许检索财报信息并写入 Notion database。不要修改本地文件、脚本、prompt、crontab 或任何自动化配置。
